# Mutopia Project — GuitarCompanion open-score catalog

GuitarCompanion includes the following three complete source editions downloaded from Mutopia Project on 2026-10-22.

| Work | Composer | Mutopia entry | Rights indicated by Mutopia | Files |
|---|---|---|---|---|
| Etude 1, Op. 60 | Matteo Carcassi | https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=13 | Public Domain | carcassi-op60-01-a4.pdf, .mid, .ly |
| Etude 3, Op. 60 | Matteo Carcassi | https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=14 | Public Domain | carcassi-op60-03-a4.pdf, .mid, .ly |
| Etude 8, Op. 60 | Matteo Carcassi | https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=15 | Public Domain | carcassi-op60-08-a4.pdf, .mid, .ly |

The entries' scores are listed as Public Domain. Retain the original credits on their PDFs and the LilyPond source when redistributing.

Source URLs use the pattern:
https://www.mutopiaproject.org/ftp/CarcassiM/O60/carcassi-op60-NN/carcassi-op60-NN-a4.pdf

The three original Mutopia editions are sheet scores (PDF), MIDI and LilyPond. GuitarCompanion additionally distributes `carcassi-op60-01.musicxml`, `carcassi-op60-03.musicxml`, and `carcassi-op60-08.musicxml`: **MIDI-derived MusicXML practice transcriptions**, not original Mutopia MusicXML and not an engraving-equivalent conversion. All original MIDI note pitches, onset times and end times have been verified in those practice editions. However, original engraving, articulation, fingering and voice layout should be consulted in the PDFs. See `scripts/mutopia/README.md` for validation steps and limitations.

Do not assume every Mutopia score has the same license. The copyright label of each source must be checked before adding another work.
